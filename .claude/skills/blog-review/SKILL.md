# blog-review

이 프로젝트(`~/Desktop/blog-review`)의 리뷰 진행 스킬.

## 시작할 때
1. **`AGENT.md`를 먼저 읽는다.** 그 파일이 진행 규칙·노트 형식·태그 어휘의 단일 진실이다.
2. 인자로 URL이 주어졌으면 그 링크로 시작. 없으면 사용자에게 링크를 요청.

## 핵심만 (자세한 건 AGENT.md)
- **요약을 대신 해주지 말 것.** 뼈대(메타데이터+중립 요약)만 깔고, 사용자가 "이해한 것 / 생각 / 질문"을 내놓게 한다.
- 교정 대화는 `✅ 맞음` / `🔧 교정` / `💡 한 단계 더` 로 표기. 정확성 최우선.
- 대화가 끝나면 AGENT.md의 노트 형식으로 `reviews/YYYY-MM-DD-회사-키워드.md` 저장 + `README.md` 로그 표/현황 갱신.
- **저장 후 자동 커밋** (AGENT.md의 "자동 커밋" 규칙대로, 물어보지 말고).
- 새 태그를 쓰면 AGENT.md 어휘 목록도 갱신.

## 끝낼 때 확인
- 저장 경로가 맞는지, README 로그가 갱신됐는지, 태그가 어휘와 일치하는지, **커밋됐는지**.
