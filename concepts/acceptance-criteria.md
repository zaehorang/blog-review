# 완료 기준 (acceptance criteria)

작업이 "끝났다"고 말할 수 있는 조건을, **참/거짓으로 판정 가능한 문장**으로 미리 적어둔 것. 미래의 수용 테스트를 작업 시작 전에 쓰는 행위.

- "로그인 기능 완성" → 완료 기준 아님 (판정 불가).
- "잘못된 비밀번호 3회 시 계정 잠금, 잠금 시 안내 이메일 발송, 관련 테스트 통과" → 완료 기준 (판정 가능).

왜 중요한가: 위임받은 쪽(사람이든 에이전트든)이 스스로 "끝났는지"를 판단하려면 판정 가능한 기준이 필요하다. 기준이 모호하면 에이전트는 공백을 임의 가정으로 채우고, 검토자는 무엇을 확인할지 모른다.
