# agent-device

iOS/Android **UI 자동화 CLI.** 에이전트가 실제 실행 중인 앱을 조작하게 해준다.

## 화면을 어떻게 읽나

스크린샷이 아니라 **접근성 트리를 압축한 스냅샷**(구조화 텍스트)으로 읽는다 → 토큰이 싸고 정확하다.

## 킬러 포인트

일회성 매크로가 아니라 **결정론적·재현 가능**하다. 그래서 "그냥 클릭"이 아니라 **E2E 테스트 도구**로 승격될 수 있다.

→ 에이전트가 코드를 짜고 → agent-device로 자기가 짠 걸 앱에서 눌러 검증 → **루프가 닫힌다.**
