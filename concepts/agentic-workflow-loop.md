# 에이전틱 워크플로우 루프 (위임·관찰·개입·검토)

에이전트에게 코딩 작업을 맡길 때 사람이 도는 순환. 한 번 훑고 끝나는 파이프라인이 아니라 **루프**다.

- **위임(delegate):** 목표·참고자료·제약·완료 기준을 주고 작업을 넘긴다.
- **관찰(observe):** 에이전트가 뭘 하는지 실시간으로 지켜본다.
- **개입(intervene):** 방향이 틀어지면 멈추고 교정한다. 타이밍이 관건 — 늦으면 잘못된 방향으로 더 파고, 빠르면 위임의 의미가 없다.
- **검토(review):** 산출물이 완료 기준을 충족하는지 사람이 최종 확인한다. 이 단계는 위임되지 않는다.

사람의 역할이 "코드를 짜는 것"에서 "이 루프를 운영하는 고수준 엔지니어링"으로 이동한다는 게 핵심.
