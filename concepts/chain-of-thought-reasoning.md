# Chain-of-Thought (CoT) / Reasoning 모델

모델이 최종 답을 내기 전에 중간 사고 과정을 거치게 하는 것. 세대가 둘로 나뉜다.

## 1세대 — 프롬프트 기법 (2022, "Let's think step by step")

학습은 전혀 건드리지 않는다. 이미 학습이 끝난 모델에 "단계별로 생각해봐"라는 지시를 프롬프트에 넣으면, 모델이 in-context로 중간 추론을 생성하고 그게 최종 정확도를 올려준다. 완전히 **프롬프트/하네스 레벨** 기법 — 모델 가중치는 그대로고, 호출하는 쪽의 요청 방식만 바뀐 것.

## 2세대 — 지금의 reasoning 모델 (o1, Claude extended thinking, Gemini thinking 등)

**학습 단계에서 명시적으로 만들어 넣은 능력.** 정답이 검증 가능한 문제(수학, 코드 실행 결과)에 대해 RL로 파인튜닝하면서, "최종 답 전에 긴 추론 과정을 생성하는 게 보상을 더 받는다"는 걸 모델이 학습한다. 이 reasoning 토큰은 프롬프트로 유도한 게 아니라 **모델 가중치 자체에 내재화된 행동** — 아무 지시 없어도 모델이 알아서 긴 사고 과정을 만들어낸다.

## 하네스는 뭘 하나

가중치가 "얼마나 깊게 생각할지"를 결정한다면, 하네스는 그 주변을 관리한다:
- thinking 토큰을 사용자에게 보여줄지 숨길지
- thinking에 쓸 토큰 예산(budget)
- thinking과 tool call을 인터리브할지, 몇 번 반복 허용할지

**비유:** 학습이 "생각하는 습관"을 만들고, 하네스는 "그 생각에 얼마나 시간/예산을 줄지"를 관리한다.
