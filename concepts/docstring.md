# docstring

코드 안에 쓰는 **문서용 주석**인데, 형식이 정해져 있어 **기계가 파싱해 문서로 뽑아낸다.**

| 언어 | 문법 | 도구 |
|---|---|---|
| Swift | `///` | DocC |
| Python | `"""` | Sphinx |
| JS/TS | `/** */` | JSDoc |

일반 주석은 아무 데나 자유롭게 쓰고 기계가 무시하지만, docstring은 **선언 바로 위**에 규격대로 쓰고 파서가 읽는다. Xcode의 옵션+클릭 팝업(Quick Help)이 이것.

## SoT로 쓰기

docstring 하나를 단일 진실로 두면 문서 사이트·MCP 인덱스 등이 전부 **같은 뿌리에서 갈라져** 어긋날 수 없다.

```
docstring → DocC 아카이브 ─┬→ 문서사이트 Markdown
                          └→ MCP용 JSON 인덱스
```

사람이 옮겨 적는 단계가 하나도 없다는 게 핵심. 대신 제약이 붙는다 — `public` 빼먹지 말 것(변환 스크립트가 이걸로 대상 선별), 파일명=타입명(문서 페이지 제목), 관련 타입은 한 파일에.
