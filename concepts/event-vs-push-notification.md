# 이벤트 알림 vs 푸시 알림

"온라인 유저에게만 간다는데 카톡은 앱 꺼도 알림 오잖아?" — **서로 다른 두 개의 알림**을 하나로 본 것이다.

| | 이벤트 알림 | 푸시 알림 |
|---|---|---|
| 경로 | [WebSocket](websocket.md) | APNs(iOS) / FCM(Android) |
| 언제 | 앱 켜진 **온라인**일 때만 | **앱 꺼져 있어도** 옴 |
| 관리 주체 | 우리 서버 | **OS** |
| 용도 | 화면 실시간 갱신 | 재유입 |

실서비스는 **둘 다** 쓴다. 웹소켓만 다루는 글을 읽을 땐 "이 글은 위쪽 레이어만 다루고 있다"고 두면 된다.

→ 실시간 기능을 설계할 땐 **두 겹을 다 떠올릴 것.**
