# Props

**`properties`의 약자.** `propagation`(이벤트 버블링의 `e.stopPropagation()`)과는 무관한 다른 개념.

부모 컴포넌트가 자식에게 내려주는 값들의 객체.

Next.js에선 페이지 컴포넌트에 넘기는 URL params·쿼리스트링이 여기 해당한다 (`DomesticSrpPageProps` 같은 타입).
