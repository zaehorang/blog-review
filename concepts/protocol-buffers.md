# Protocol Buffers (Protobuf)

[gRPC](grpc.md)가 기본으로 쓰는 **데이터 직렬화 포맷 + IDL(인터페이스 정의 언어)**. `.proto` 파일에 메시지 구조와 함수(서비스) 시그니처를 정의하면, `protoc` 컴파일러가 여러 언어로 클라이언트/서버 코드를 **자동 생성**한다.

- 구조를 **바이너리 형식**으로 직렬화 — JSON(텍스트) 대비 빠르고 작지만 사람이 읽을 순 없다.
- 필드는 **번호로 식별**돼서, 새 필드를 추가해도 구버전 클라이언트/서버가 모르는 필드는 그냥 무시하고 넘어간다 → 하위 호환을 지키는 스키마 진화가 가능.
- proto 정의를 클라이언트·서버가 **공유해야** 하므로 [REST](rest.md)의 JSON보다 결합이 긴밀하다 — 대신 타입 안정성과 코드 자동생성으로 개발 시간이 준다.
