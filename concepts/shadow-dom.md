# Shadow DOM

커스텀 엘리먼트 안에 만드는 **격리된 DOM 트리**. 스타일과 구조가 바깥 문서와 섞이지 않는다.

## 막는 방향을 헷갈리기 쉽다

| 방향 | 동작 |
|---|---|
| **안 → 밖** | 컴포넌트 자기 CSS가 shadow 안에 갇힘 → 부모를 오염시키지 않음 (**장점, 자동**) |
| **밖 → 안** | 부모의 전역 폰트·디자인 토큰이 경계를 **못 넘어옴** (**성가심, 수동 해결 필요**) |

즉 "필요한 스타일을 직접 찾아 입혀줘야 한다"가 맞는 건 **밖→안 방향**뿐이다. 컴포넌트 자기 스타일은 알아서 격리된다. 부모 디자인 토큰을 쓰려면 shadow root 안에 다시 주입해야 한다.
