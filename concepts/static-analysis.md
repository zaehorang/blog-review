# 정적 분석

**소스코드만 보고 판단하는 것.** 실행과 무관하다.

흔한 오해: "실행해서 문제가 생기면 체커가 잡아준다."
→ 아니다. **코드를 한 번도 안 돌려도** 에러를 찾아낸다. 실행 결과를 관찰해서 잡는 게 아니라, 저장하는 순간 독립적으로 같은 소스를 훑는 것.

```
[동적] 실행 → 문제 발생 → 감지     (테스트, 런타임 모니터링)
[정적] 소스만 읽음 → 판단          (타입체커, 린터, 보안 스캐너)
```

타입체커·린터·정적 보안 스캐너(SAST) 전부 같은 원리다.
