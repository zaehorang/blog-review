# 웹뷰 (WebView)

앱 안에 박아 넣은 **브라우저 컴포넌트**(iOS `WKWebView`, Android `WebView`)에 띄운 웹페이지.
렌더링하는 건 똑같은 HTML/CSS/JS다.

> **"웹 vs 웹뷰"는 렌더링 기술 차이가 아니라 실행 컨테이너 차이.**

| | 웹 (브라우저) | 웹뷰 (앱 안) |
|---|---|---|
| 인증 | 쿠키 | 앱이 쥔 토큰을 브릿지로 |
| 네비게이션 | 브라우저 히스토리·주소창 | 앱 화면 스택 + [안드로이드 백키](android-back-key.md) |
| 상단/하단 바 | 웹이 그림 | 앱이 그릴 수도 |
| 네이티브 기능 | 불가 | 브릿지로 가능 (캘린더 호출, 스키마 연동) |
| URL 공유 | 됨 | 사실상 안 됨 |

**반응형 웹은 또 다른 축**이다 — 화면 폭에 따라 레이아웃이 바뀌는 웹. 웹/모바일웹은 같은 코드에 폭만 다르고, 웹뷰는 컨테이너가 다르다.

⚠️ **웹뷰는 네이티브가 아니다.** "네이티브 앱 안에서 열리는 웹"이지 네이티브 코드가 아니다. 앱은 웹뷰를 띄우는 컨테이너이자 브릿지 상대일 뿐. 진짜 네이티브 화면(RN/KMP 영역)은 렌더링 엔진 자체가 달라서 "웹과 화면 한 벌"이 성립하지 않는다.
