`CLAUDE.md`에는 트리거와 문서 탐색 순서만 두고, 실제 절차·검증·프로젝트 사실은 `.claude/` 아래로 분리한 예시다.

- `CLAUDE.md`: 필요한 문서로 안내하는 라우터
- `.claude/workflows/`: 작업 절차
- `.claude/checklists/`: 완료 전 검증 기준
- `.claude/references/`: 프로젝트에 오래 남는 사실

회사나 원문 출처는 이 README에서만 연결하고, 프로젝트 파일·폴더명은 예시가 다루는 주제와 역할만 표현한다.
