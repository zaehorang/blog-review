CDN 캐시 버스팅 확인

이 페이지는 app.js를 Cache-Control: max-age=3600(1시간)으로 불러옵니다.

로딩 중...

실습 순서

  1. 지금 화면에 "버전 1"이 보이는지 확인.
  2. public/app.js 파일을 열어 '버전 1'을 '버전 2'로 바꾸고 저장.
  3. 이 페이지를 일반 새로고침(⌘R)만 해보기 → 아직도 "버전 1"이면 캐시가 살아있는 것.
  4. 이 파일(index.html)의 <script src="app.js">를
    <script src="app.js?v=2">로 바꾸고 저장 → 새로고침하면 즉시 "버전 2"가 뜨는지 확인.

→ 4번이 실무의 "콘텐츠 해시 파일명" 방식과 같은 원리: URL 자체를 바꿔서 캐시를 무조건 미스나게 만드는 것.
