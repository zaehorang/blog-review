# 04. CDN 캐시 버스팅

> 어느 리뷰에서: [`../../../reviews/2026-08-04-oliveyoung-vue-web-components.md`](../../../reviews/2026-08-04-oliveyoung-vue-web-components.md)

## 확인하는 것
CDN이 재배포 후에도 옛 버전을 계속 물고 있는 문제(TTL), 그리고 콘텐츠 해시/쿼리스트링으로 캐시를 즉시 무효화하는 방법.

## 실행
```bash
node server.js
```
브라우저로 http://localhost:5701 접속 후, `public/index.html` 안의 "실습 순서" 그대로 따라가면 됩니다.

## 볼 것
1. `app.js`를 고쳐도 **일반 새로고침으로는 안 바뀌는 것** — `Cache-Control: max-age=3600`이 살아있기 때문 (TTL 미만료).
2. `?v=2` 붙이는 순간 **바로 반영되는 것** — URL이 바뀌니 캐시 입장에서 "처음 보는 요청"이 되어 무조건 원본에서 새로 받아옴.

## 참고
실무에서 하드 리프레시(⌘⇧R)는 브라우저 캐시를 통째로 무시하기 때문에 이 데모의 문제를 감춰버립니다. 반드시 **일반 새로고침**으로 테스트하세요 — 실제 CDN 캐시(TTL)는 사용자의 새로고침 방식과 무관하게 살아있으니까요.
