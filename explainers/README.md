# 🔬 동작 원리 시각화

글로 읽으면 안 잡히는 **내부 동작**을 단계별로 따라가며 보는 단일 HTML 파일들.

각 파일은 단계마다 **① 상태 다이어그램(지금 어디에 있나) + ② 실제 산출물의 before/after(뭐가 바뀌었나) + ③ 왜 이 단계가 필요한가**를 나란히 보여준다.
브라우저로 파일을 열기만 하면 된다 — 설치·빌드 없음.

- `examples/`(직접 짜보는 실습)와 구분한다. 여기는 **읽고 이해하는 자료**.
- 폴더명은 영문 케밥 슬러그, 기술·개념만 (회사명 X). 출처는 파일 안 푸터에 링크.
- 만드는 규칙은 `mechanism-explainer` 스킬, 저장 위치 정의는 [`AGENT.md`](../AGENT.md).
